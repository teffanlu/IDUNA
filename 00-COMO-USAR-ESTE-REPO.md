# 00 — Cómo usar este repositorio (Reglas Maestras)

Este repo (`teffanlu/IDUNA`) es la **única fuente de verdad** del proyecto IDUNA. Varios chats trabajan sobre él. Los chats no recuerdan; **el repo recuerda**.

---

## Principio único
> Toda decisión, dato o avance se guarda aquí. Si no está en el repo, no existe.

---

## 1. Al INICIAR un chat
Pega esto (ajusta tema y experto):
```
Proyecto: IDUNA (skincare + aparatología, Maracaibo).
Fuente de verdad: repo teffanlu/IDUNA (rama main).

1. Clona y LEE el repo completo antes de responder.
2. Confírmame en 2 líneas qué entendiste del estado actual.
3. Hoy trabajamos en: [TEMA]. Configúrate como: [experto].
```

## 2. Durante el chat
- Un solo tema por chat (no mezclar compras con contenido, etc.).
- Si surge algo de otra área: anótalo, pero desarróllalo en el chat que corresponde.

## 3. Al GUARDAR (al terminar o en hitos)
Pega esto:
```
Guarda lo avanzado en el repo teffanlu/IDUNA:
1. Haz PULL de main primero.
2. Guarda en la carpeta que corresponde al tema.
3. No dupliques: si el tema ya existe, ACTUALIZA el archivo.
4. Actualiza el README si creas archivos nuevos.
5. Commit + push a main.
6. Dime qué archivos creaste/actualizaste.
```

---

## Las 4 leyes de oro
1. **Todo en `main`** — sin ramas dispersas.
2. **PULL antes de PUSH** — evita choques entre chats.
3. **El README es el índice** — mantenerlo actualizado.
4. **Un tema = un chat = una carpeta** — sin mezclas.

## Mapa chat -> carpeta
| Chat | Carpeta | Experto sugerido |
|---|---|---|
| Marca / visual | `01-estrategia/`, `02-identidad-visual/` | Disenador de identidad |
| Negocio / finanzas | `03-negocio/` | Consultor de negocios |
| Compras / importacion | `04-compras/` | Experto en sourcing/importacion |
| Contenido / redes | `05-contenido/` (por crear) | Estratega de contenido |

## Mantenimiento (cada 2-3 semanas)
```
Audita el repo teffanlu/IDUNA: revisa duplicados, info contradictoria
entre carpetas y README desactualizado. Dime que encontraste.
```
